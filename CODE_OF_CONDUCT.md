# Contributor Covenant Code of Conduct

## Our pledge

We pledge to make participation in Radar Bench a harassment-free experience
for everyone, regardless of age, body size, visible or invisible disability,
ethnicity, sex characteristics, gender identity and expression, level of
experience, education, socioeconomic status, nationality, personal
appearance, race, religion, or sexual identity and orientation.

## Our standards

Examples of behavior that contributes to a positive environment include
empathy, respect, constructive feedback, accepting responsibility, and
prioritizing the safety and privacy implications of executing third-party
code.

Unacceptable behavior includes harassment, discrimination, threats, doxxing,
publishing secrets, deliberate isolation weakening, and other conduct that
would reasonably be considered inappropriate in a professional setting.

## Enforcement

Report unacceptable behavior through the private GitHub repository security
channel. If that channel is unavailable, open a minimal public issue without
private details and request maintainer follow-up. Maintainers will review and
may remove, edit, or reject contributions that violate this code.

This code is adapted from the Contributor Covenant, version 2.1:
https://www.contributor-covenant.org/version/2/1/code_of_conduct.html
