# Code of Conduct

Radar Bench follows the Contributor Covenant 2.1. Participants are expected to be welcoming, respectful, constructive, and attentive to the safety and privacy implications of executing third-party code.

Unacceptable behavior includes harassment, discrimination, threats, doxxing, publishing secrets, and deliberately weakening benchmark isolation. Report concerns privately to the project maintainers through the project security or maintainer channel when available.
