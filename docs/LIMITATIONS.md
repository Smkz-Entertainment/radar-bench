# Limitations

The canonical suite is small: five historical positives and twenty
constructed safety twins. Its results are not population estimates.

The frozen agentic investigator failed the decisive product hypothesis and the
cross-repository case. Radar Bench therefore does not ship an attribution
agent, automatic fixes, GitHub comments, or issue creation.

Historical wheels remain external inputs and may be unavailable because of
upstream retention, licensing, platform, or resolver constraints. A blocked
case is evidence about reproducibility limits, not a correct or incorrect
investigator prediction.

Docker is required for the canonical executor. The supported architecture is
Linux/x86-64, including Docker Desktop's Linux engine when it reports that
capability. Hardware-specific incidents are not silently substituted.
