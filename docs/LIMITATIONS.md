# Limitations

The corpus is small, concentrated in a few repositories, and canonical execution requires a Linux/x86-64 Docker engine. Five historical artifact bundles are not redistributed. The safety set is constructed and opaque, not a random sample of incidents. The benchmark does not establish population accuracy, production safety, cross-platform container-engine support, or autonomous repair capability.

The decisive run also showed that good abstention can coexist with failure to attribute. Radar Bench therefore reports safety and attribution separately and does not collapse them into one accuracy number.
