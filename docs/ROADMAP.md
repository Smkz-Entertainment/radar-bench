# Roadmap

The Radar Bench engineering foundation is complete enough for the v1 OSS benchmark. There is no roadmap for an autonomous attribution product, UI, GitHub bot, automatic issue creation, or autonomous fixes.

The supported next work is deliberately narrow:

1. maintain the executable suite and its integrity checks;
2. accept new historical cases only through sealing and explicit rejection evidence;
3. improve the benchmark runner only when a real case proves the executor is defective;
4. use prospective failures as research inputs, without weakening temporal or safety gates.

The v0.1–v0.7 milestones remain immutable research history. Do not add another replay-certification phase or tune the frozen v0.5 investigator.
