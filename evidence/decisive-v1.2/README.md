# decisive-v1.2 evidence

This directory records the current package suite's evaluator/candidate boundary,
candidate-only solvability reference, real protocol smoke, artifact integrity,
resource mirror, and concise release/security checks. The evaluator asset is a
separately distributed host input and is never packaged into the candidate wheel
or mounted into the candidate container.

The v1.2 suite contract remains the immutable `1.1.0` contract. Package version
`1.1.1` contains launch-hygiene and release-engineering changes only.
